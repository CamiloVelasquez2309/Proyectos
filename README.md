Portafolio de Proyectos - Camilo Velásquez
Analista SIG y Datos Geoespaciales

Este repositorio agrupa proyectos prácticos donde aplico análisis espacial y programación a problemas operativos reales, principalmente en logística de campo y medio ambiente. El enfoque de estos ejercicios es documentar flujos de trabajo que van desde la ingesta de datos hasta la entrega de un insumo final.

Proyectos
Análisis NDVI y Hillshade (/ndvi-hillshade)
Ejercicio de teledetección para evaluar el estado de la vegetación a partir de un ortomosaico, combinando el índice NDVI con un modelo de sombreado (Hillshade) para mejorar la interpretación visual del terreno.

Herramientas: Python (Rasterio, NumPy, Scikit-Image), QGIS.
Entregable: Notebook de procesamiento y mapa temático final en formato PDF.
Geocodificación Inversa Masiva (/python-geocoding)
Script diseñado para limpiar y enriquecer bases de datos que solo contienen coordenadas, convirtiéndolas en direcciones legibles mediante la API de Google Maps.

Herramientas: Python, Pandas, Requests.
Entregable: Script modular con manejo seguro de variables de entorno y dataset de prueba.
