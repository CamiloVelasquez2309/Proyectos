# ETL: Geocodificación Inversa
**Herramientas:** Python, Pandas, Google Maps API.

Script para automatizar la geocodificación inversa (coordenadas -> direcciones) de bases de datos masivas. Las credenciales están manejadas de forma segura mediante un archivo local.
Proceso realizado de manera constante y en constante cambio debido a las metodologias de trabajo y buscando aminorar costos.
